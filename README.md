# Uber Data Analysis Dashboard (Power BI) 📊🚗

This repository contains an interactive **Power BI Dashboard** developed to analyze Uber performance indicators, vehicle distribution, and revenue patterns.

## 🚀 Project Overview
The goal of this project is to transform raw ride-sharing data into actionable business insights. By leveraging advanced data modeling and custom UI/UX design within Power BI, the dashboard maps key operational metrics to help stakeholders understand trends, revenue streams, and fleet performance efficiently.

## 🛠️ Key Features & Technical Highlights
* **Interactive Visualizations:** Custom charts and graphs analyzing trip distributions, revenue growth, and operational bottlenecks.
* **Refined UI/UX Design:** Implemented custom color schemes, visual borders, and seamless page navigation flows to enhance presentation clarity.
* **Data Integration:** Cleaned and structured data pipelines powering the underlying data model.

## 📂 Repository Structure
* `Report/` - Contains the Power BI report definition, pages, and layout files.
* `Report/StaticResources/` - Includes registered icons, logos (Uber branding), and UI assets.
* `Report/SharedResources/` - Base themes and styling configurations (e.g., Fluent themes).

## 💡 Tech Stack
* **Tool:** Microsoft Power BI
* **Design Elements:** Custom JSON themes, tailored color palettes, and structured navigation.
